features:
  - title: 🎮 PS2 遙控飆車體驗
    details: 標配 2.4G PS2 無線接收器與手把！開機隨連，隨插即用，享受賽車級的靈敏操控與飆速樂趣！
  - title: 🎁 免安裝超好上手
    details: 打開 Chrome 或 Edge 就能拖積木、上傳到小車，不用安裝任何軟體；教室電腦不能上網時，也可以安裝 MBC 圖控編程 軟體再匯入 jBot 積木包！
  - title: 🧩 積木拖拉寫程式
    details: 網頁版與 MBC 圖控編程 安裝版都能用，拖拉積木即可控制小車行駛特定公分、循線與 RGB 彩燈互動；加裝選購模組還能做雷射防撞與 OLED 顯示，零基礎也能秒懂！
  - title: 🎯 雙編碼器馬達閉迴路控制
    details: 每顆馬達配備霍爾編碼器，精準回授輪胎圈數。指定距離與轉向角度不再失準，競賽與教學最穩定！
  - title: ⚡ 內建感測器＋I2C 擴充
    details: 基本套件內建雙路紅外線循線感測器、4 顆 RGB 彩燈與按鈕；車上預留 I2C 擴充插槽與 2 組伺服馬達接頭，可另購雷射測距、OLED 螢幕、伺服馬達與 MBC 感測器（不含在基本套件）。
  - title: 💻 Arduino C++ 無縫進階
    details: 提供完整的底層 C++ 類別庫封裝，國高中生與大專生可直接切換 Arduino IDE 進行演算法與 PID 控制深度研習。

  <h2 style="font-size: 1.8rem; font-weight: 700; text-align: center; margin-bottom: 24px;">🔥 精選常見問答 (FAQ)</h2>

  ::: details Q1：MBC-jBot 適合幾歲的孩子或哪些年級學習？
  MBC-jBot 涵蓋從國小中年級到高中、大專的全學習階段：
  - **國小中年級**：以 PS2 無線手把遙控、RGB 彩燈互動為主，培養機器人興趣。
  - **國小高年級 ~ 國中**：用網頁版或 MBC 圖控編程 積木學習程式邏輯、紅外線循線與公分距離控制。
  - **高中與創客競賽**：銜接 Arduino C++ 開發手冊，練習中斷服務與閉迴路控制。
  :::

  ::: details Q2：初學者完全不會寫程式，可以自己玩起來嗎？
  **完全沒問題！** 打開[網頁版](/guide/web-start)就能寫程式，不用安裝任何軟體（也可以安裝 MBC 圖控編程 軟體），搭配循序漸進的線上教學手冊，小讀者只要像堆積木一樣把指令拼起來，小車就會立刻按照指示前進、轉向與閃爍燈光！
  :::

  ::: details Q3：MBC-jBot 與市售普通 Arduino 自走車有何不同？
  市面上常見的自走車多採用普通減速馬達（無編碼器），行走距離會隨著電池電量降低而嚴重縮水。  
  **MBC-jBot 每顆馬達都配備霍爾編碼器（閉迴路控制）**，能即時計算輪胎圈數與旋轉角度，真正做到「精確走 30 公分」與「原地轉向 90 度」，大幅提升課堂與科技競賽成功率！
  :::
