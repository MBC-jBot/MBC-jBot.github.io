  <h2 style="font-size: 1.8rem; font-weight: 700; text-align: center; margin-bottom: 24px;">🔥 精選常見問答 (FAQ)</h2>

  ::: details Q1：MBC-jBot 適合幾歲的孩子或哪些年級學習？
  MBC-jBot 涵蓋從國小中年級到高中、大專的全學習階段：
  - **國小中年級**：以 PS2 無線手把遙控、聲光音效互動為主，培養機器人興趣。
  - **國小高年級 ~ 國中**：學習 Scratch 3.0 / OpenBlock 積木邏輯、紅外線循線、超音波避障與公分距離控制。
  - **高中與創客競賽**：銜接 Arduino C++ 開發手冊，練習中斷服務與閉迴路控制。
  :::

  ::: details Q2：初學者完全不會寫程式，可以自己玩起來嗎？
  **完全沒問題！** 我們提供專屬的「一鍵安裝包」免設定環境，搭配循序漸進的線上教學手冊，小讀者只要像堆積木一樣把指令拼起來，小車就會立刻按照指示前進、轉向與閃爍燈光！
  :::

  ::: details Q3：MBC-jBot 與市售普通 Arduino 自走車有何不同？
  市面上常見的自走車多採用普通減速馬達（無編碼器），行走距離會隨著電池電量降低而嚴重縮水。  
  **MBC-jBot 配備雙路光電編碼器（閉迴路控制）**，能即時計算輪胎圈數與旋轉角度，真正做到「精確走 30 公分」與「原地轉向 90 度」，大幅提升課堂與科技競賽成功率！
  :::
