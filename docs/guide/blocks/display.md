# 2. 彩燈與螢幕顯示

MBC-jBot 不僅能跑，還能透過炫麗的 RGB 燈光與 OLED 螢幕與您互動！

> [!IMPORTANT]
> **需加購：** OLED 小螢幕（SSD1315）不含在基本套件，在 [擴充包](/guide/store) 裡。彩燈積木不用加購，基本套件就能做。

::: warning 0.49 吋螢幕正在調整
擴充包附的是 **0.49 吋（64×32）** 小螢幕，目前的 OLED 積木是照 **0.96 吋（128×64）** 螢幕設計的。我們正在調整成 0.49 吋版本，更新後座標範圍會改成 **X：0～7、Y：0～1**（一次顯示 2 行、每行 8 個字）。使用 0.96 吋螢幕的老師不受影響。
:::

## 積木總覽

*   **LED 燈光積木**（「**jBot 彩燈**」分類）：可以設定底盤 1~4 號燈的顏色（紅、綠、藍各 0~255），或是選擇關閉所有燈光。
*   **OLED 顯示積木**（「**jBot 螢幕**」分類）：可以清空螢幕，或在指定的座標 (X: 0~15, Y: 0~3) 上顯示英文、數字與符號（0.96 吋螢幕；0.49 吋見上方說明）。

### ⚠️ 常見錯誤提醒

*   **OLED 螢幕超出範圍**：OLED 螢幕的解析度有限。0.96 吋螢幕的 X 座標（左右）只能填寫 `0` 到 `15`，Y 座標（上下）只能填寫 `0` 到 `3`（0.49 吋更新後是 X `0`～`7`、Y `0`～`1`）。如果您輸入了太大的數字，文字會超出螢幕邊界而看不見喔！
*   **OLED 疊字問題**：如果您要在同一個位置顯示新的文字，記得先使用「清空 OLED 螢幕」積木，否則新舊文字會疊加在一起變成亂碼。
*   **只能顯示英文和數字**：OLED 目前支援英文、數字與符號，中文字會顯示成 `?`。
