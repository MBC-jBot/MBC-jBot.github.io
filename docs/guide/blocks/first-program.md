恭喜您完成了前面的基礎教學！現在，我們準備了一個完整的「**PS2 遙控車與全方位控制**」範例程式。

*   🎮 **PS2 手把**：類比搖桿與按鍵雙重控制
*   🖥️ **序列埠監控**：即時回傳馬達數值

## 📥 範例程式下載

> 🎁 **<a href="/example/web/lesson6-ps2-demo.jbot" download>點此下載 PS2 遙控範例程式（lesson6-ps2-demo.jbot）</a>**

### 如何使用這個檔案？
1. 下載上方的 `lesson6-ps2-demo.jbot` 檔案到您的電腦中。
2. 打開 [jBot 積木編程網頁版](https://jbot-block-ide.mbcrobot.workers.dev)。
3. 點擊上方的 **「開啟檔案」**，選擇您剛剛下載的檔案。
4. 用 USB 線接上小車，按 **「上傳到 jBot」** 即可馬上開始遙控！

> 💡 只想先試試遙控？網頁版的「範例」選單有一支比較短的「**PS2 手把遙控**」（方向鍵控制前後左右）。
