# 開始使用：網頁版（免安裝）

打開瀏覽器就能寫程式，**不用安裝任何軟體**。拖拉積木、按一下上傳，小車就會照著你的程式動起來！

> 🌐 **網頁版網址**：[https://jbot-block-ide.mbcrobot.workers.dev](https://jbot-block-ide.mbcrobot.workers.dev)
>
> 想用電腦安裝的版本？請看 [安裝版：MBC 圖控編程＋jBot 積木](/guide/graphic-programming)。兩個版本的積木功能相同，本站每一課都附兩種畫法。

## 第一步：準備電腦與瀏覽器

* **瀏覽器**：請用電腦版的 **Google Chrome** 或 **Microsoft Edge**（Windows、Mac、Chromebook 都可以）。Safari、Firefox 和手機不能把程式傳到小車。
* **網路**：第一次打開網站會下載編譯器（約 11 MB），之後會記住，不用重新下載。
* 下方狀態列出現「**編譯器就緒**」，就可以開始了。

![jBot 積木編程網頁版畫面](/images/web/overview.webp)

畫面說明：

* **左邊**：積木分類（jBot 運動、感測、彩燈、螢幕、舵機、遙控⋯）。
* **中間**：把積木拖到這裡拼程式。
* **右邊**：「C++ 程式碼」分頁會即時顯示積木變成的程式；「序列埠」分頁可以看小車傳回來的數值。
* **上方**：範例、開啟／儲存檔案、檢查程式、**上傳到 jBot**。

## 第二步：用 USB 線接上小車

1. 拿出盒內的 **Type-C 傳輸線**，一端插小車、另一端插電腦。
2. **Windows** 第一次使用時，如果等一下的清單裡找不到小車，請安裝 [👉 CH340 驅動程式](https://drive.google.com/drive/folders/1IQjFcSHTmrgY4PyfSliELT39hWaP1skf?usp=sharing)。Mac 和 Chromebook 通常不用另外安裝。

## 第三步：拼出第一支程式

程式由兩顆開頭積木組成（跟安裝版 MBC 圖控編程一樣），積木要接在它們下面：

* **開機時執行一次**：開機後從上到下做一次。底下第一個積木一定要放「**初始化 jBot 機器人**」（新專案已經幫你放好了）。
* **主迴圈 (一直重複)**：一直重複做的事情接在這裡。

試著拼出下面的程式：前進 2 秒後停下來。

![第一支程式：前進 2 秒後停下](/images/web/first-program.webp)

> 📥 不想自己拼？<a href="/example/web/first-program.jbot" download>下載這支範例（first-program.jbot）</a>，在網頁版按「**開啟檔案**」打開。

## 第四步：上傳到小車

1. 按右上角的「**上傳到 jBot**」。
2. 第一次會跳出選擇視窗，選「**USB Serial (COM 數字)**」（有的電腦顯示「USB-SERIAL CH340」），再按「**連線**」。之後就不用再選。
3. 進度條跑完就完成了（約 3～5 秒），上傳時小車會自己重新開機。

::: tip 🚀 程式執行提醒
**有裝電池時**，小車開機後彩燈會閃綠燈，**按一下車頂的啟動按鈕**才會開始跑程式（避免一上傳車子就衝出去）。只插 USB、沒有電池時會直接開始。
:::

## 其他常用功能

* **範例**：上方「範例」選單有彩燈閃爍、走正方形、循線、雷射避障、PS2 遙控、OLED 電子名牌等現成程式。
* **自動儲存**：積木會自動存在這台電腦的瀏覽器裡，關掉網頁再打開還在（無痕視窗不會保存）。
* **儲存／開啟檔案**：換電腦或交作業時，按「儲存檔案」下載 `.jbot` 檔，之後用「開啟檔案」打開。
* **看數值**：用「序列埠印出」積木，再打開右邊的「序列埠」分頁。
* **匯出 .ino**：下載 C++ 程式，可以用 Arduino IDE 打開，進階學習請看 [C++ 開發手冊](/api/)。
