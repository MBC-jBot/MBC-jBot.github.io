# 🛒 加購專區

MBC-jBot 基本套件已經可以學馬達、編碼器、循線、彩燈、按鈕與 PS2 遙控。想做雷射防撞、螢幕顯示或機械手臂，再加購下面的擴充包。

::: tip 基本套件有什麼？
內建：小車主機（Arduino Uno 相容）、兩顆附霍爾編碼器的馬達、雙路紅外線循線感測器、4 顆 RGB 彩燈、按鈕、18650 鋰電池（USB 充電）、PS2 無線手把與接收器、Type-C 傳輸線。**沒有**超音波感測器與蜂鳴器。完整對照見 [常見問題 Q12](/guide/faq)。
:::

## 🔌 MBC I2C 感測器（另購）

小車上的 **I2C 擴充插槽**可以再接 MBC 的 I2C 感測器，例如陀螺儀、循跡感測器、無線手把、馬達擴充板。網頁版的「I2C 感應器」分類已經有這些模組的積木。規格與型號請看 [MBC 感測器產品網站](https://mbc-pro-sensors.github.io/)，購買一樣透過官方 LINE 洽詢。

## 🧱 樂高積木

車頭的三個圓孔是**樂高孔**，可以用樂高插銷接上樂高積木，自己加結構或比賽需要的機構。**樂高積木請自備**，不含在基本套件與擴充包裡。
