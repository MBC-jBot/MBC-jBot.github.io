## 🎓 教學與課程篇

::: details Q1：MBC-jBot 適合幾歲或哪些年級的學生？
**答：**  
MBC-jBot 專為 **國小中高年級、國中生活科技、高中創客社團與科技競賽** 打造：
- **國小中年級**：以「寓教於樂」為主，體驗 PS2 無線飆車、燈光與音效控制。
- **國小高年級 ~ 國中**：學習 Scratch 3.0 / OpenBlock 積木邏輯、雙編碼馬達指定距離行駛、紅外線黑白線循跡、超音波避障。
- **高中與大專**：無縫過渡至 Arduino C++，直接調用底層 API 與中斷處理，進行自走車競速與精確 PID 控制。
:::

完全可以！本網站提供圖文並茂的步驟式教學與影片：
1. 先安裝好「一鍵安裝包」。
2. 打開積木編輯器，拖拉專屬小車積木（如「前進 30 公分」、「亮綠燈」、「播放嗶聲」）。
3. 接上 USB 線，點擊上傳即可在幾秒內看到實體小車做出對應動作，零門檻獲得滿滿成就感！
:::

## 🛠️ 環境安裝與硬體排錯篇

::: details Q4：軟體安裝會不會很複雜？課堂電腦常遇到權限或驅動問題怎麼辦？
**答：**  
少伯創意機器人特別為教學現場開發了 **Windows 一鍵安裝包**：
- 整合了 OpenBlock / Scratch 編輯環境。
- 自動安裝 CH340 / CP2102 序列埠通訊驅動程式。
- 課堂前只需在電腦點擊執行安裝一次，即可全班隨插即用，徹底告別傳統安裝驅動的惡夢！
:::

::: details Q5：PS2 無線手把無法遙控小車，該如何排查？
**答：**  
請依照以下步驟檢驗：
1. **檢查手把電池**：確認手把內的 2 顆四號 (AAA) 電池電量充足以防訊號不良。
2. **檢查手把開關**：手把開關撥至 `ON`，觀察手把燈號。
3. **檢查小車接收器指示燈**：小車電源開啟後，接收模組紅燈亮起；手把開機後綠燈轉為常亮，即代表配對成功。若綠燈持續閃爍，代表尚未成功配對，請重開手把開關。
4. **確認燒錄韌體**：確認小車已下載並燒錄「PS2 遙控」範例程式（或積木程式中有正確啟用 PS2 讀取指令）。
:::

::: details Q6：小車在行駛時容易偏向一側，該如何校正？
**答：**  
MBC-jBot 配有**雙光電編碼器**：
- 在積木程式中，請優先使用帶有距離控制的指令（例如「以速度 100 前進 30 公分」），小車韌體會自動以編碼器閉迴路修正兩輪轉速。
- 若使用純手動 PWM 轉速輸出，因地面摩擦力或輪胎微小差異可能有微量偏移，可透過軟體在左/右輪速度加上微調補償值。
:::

## 🧩 程式與感測器應用篇

::: details Q7：MBC-jBot 與市售一般 Arduino 自走車有什麼不同？
**答：**  
一般入門款自走車多採用普通 TT 馬達（無編碼器），只能以時間控制（例如「前進 1 秒」），當電池電量從 8V 掉到 7V 時行駛距離就會大幅縮水。  
**MBC-jBot 的三大核心優勢：**
1. **內建雙編碼器馬達**：以真實輪胎圈數與脈衝數閉迴路計算，行駛距離固定，不受電量變化影響。
2. **標配 PS2 遙控器**：即刻實現實體飆車，課堂互動感最強。
3. **積木與 C++ 雙環境無縫支援**：從小學積木到大學專案一套搞定，擴充壽命長。
:::

::: details Q8：如何利用超音波與循線感測器完成自動避障或迷宮任務？
**答：**  
- **超音波避障**：小車前端配備超音波感測器，積木程式中直接讀取「前方障礙物距離 (cm)」，當小於安全距離（例如 20 cm）時自動倒退或旋轉避開。
- **循線挑戰**：底盤配有紅外線循線感測器，能即時判斷黑色軌跡與白色地面，配合我們的教學手冊即可快速寫出流暢循跡邏輯。
:::
