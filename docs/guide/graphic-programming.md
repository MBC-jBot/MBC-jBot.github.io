# 安裝版：MBC 圖控編程＋jBot 積木

安裝版適合**教室電腦不能上網**、或習慣用電腦軟體的老師。只要兩個步驟：先安裝 **MBC 圖控編程** 主程式，再把 **jBot 積木包**匯入進去。

::: tip 🌐 不想安裝軟體？
直接用瀏覽器寫程式、上傳到小車，請看 [開始使用：網頁版（免安裝）](/guide/web-start)。兩個版本的 jBot 積木一模一樣，本站每一課都附兩種畫法。
:::

## 第一步：安裝 MBC 圖控編程主程式

> 📥 **[點此到 Google 雲端硬碟下載安裝檔](https://drive.google.com/drive/folders/17N6sIzMt2uiSEI7hVB_qGaBW5gWlcCpo)**（`MBC BlockCode-安裝檔-1.0.0.exe`，約 150 MB，Windows 10／11）
>
> 檔案比較大，雲端硬碟會顯示「無法掃描病毒」的提示，按「**仍要下載**」即可。

1. 雙擊安裝檔（檔名類似 `MBC BlockCode-安裝檔-1.0.0.exe`）。
2. Windows 可能會跳出「這個應用程式可能會對你的裝置造成損害」的提示，點選**仍要執行**（安裝檔沒有付費的數位簽章，不代表軟體有問題）。
3. 安裝資料夾**建議直接用預設的位置**（`C:\MBC_BlockCode`），一路按**下一步**到安裝完成。

更完整的軟體操作說明，請看 [MBC 圖控編程使用手冊](https://mbcrobot.github.io/mbc-blockcode-guide/)。

## 第二步：匯入 jBot 積木包

> 📦 **<a href="/downloads/mbc_jbot.abpkz" download>點此下載 jBot 積木包（mbc_jbot.abpkz）</a>**：裡面有 jBot 專用積木和小車的函式庫，匯入一次就好。

1. 打開 MBC 圖控編程，點左邊積木分類最下面的「**創建積木**」。
2. 按「**📥 匯入積木檔**」，選擇剛剛下載的 `mbc_jbot.abpkz`。

![創建積木分類裡的「匯入積木檔」按鈕](/images/desktop/import-button.webp)

3. 匯入完成後，左邊會多出「**MBC-jBot 核心套件**」，點開就有 jBot 運動、感測、彩燈、螢幕、舵機、遙控等分類。

![匯入後出現的 MBC-jBot 核心套件](/images/desktop/jbot-categories.webp)

> 💡 積木包更新時，重新下載再匯入一次即可。如果軟體說「這個檔案裡的積木你已經都有了」，請先在「創建積木 →🗑 刪除主類別／子類別」刪掉舊的「MBC-jBot 核心套件」再匯入。

## 第三步：安裝驅動與連線

1. 拿出盒內的 **Type-C 傳輸線**，一端插小車、另一端插電腦。
2. 第一次使用時，點上方選單的「**說明**」→「**安裝 USB 驅動程式**」→「**自動偵測我的板子需要哪一種…**」，跟著安裝精靈完成 CH340 驅動程式。
3. 右上角的連接埠選單保持「**自動偵測**」就好；電腦接了很多 USB 裝置時，也可以手動選小車的 COM 埠。

## 第四步：拼出第一支程式並燒錄

程式由兩顆開頭積木組成（跟網頁版一樣），積木要接在它們下面：

* **開機時執行一次**：開機後從上到下做一次。底下第一個積木一定要放「**初始化 jBot 機器人**」。
* **主迴圈 (一直重複)**：一直重複做的事情接在這裡。

試著拼出下面的程式：前進 2 秒後停下來。

![第一支程式：前進 2 秒後停下（安裝版）](/images/desktop/first-program.webp)

> 📥 不想自己拼？<a href="/example/desktop/first-program.abp" download>下載這支範例（first-program.abp）</a>，在軟體按工具列的 📂（開啟程式檔案，Ctrl+O）打開。

拼好之後按右上角綠色的「**編譯並燒錄**」，等進度跑完就完成了。

::: tip 🚀 程式執行提醒
燒錄完成後，請記得**打開小車電源開關**，並按下車頂的「**啟動按鈕**」，小車才會開始執行您的程式喔！
:::
